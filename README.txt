# RONNIE Budget Planner

A mobile-friendly, installable web app prototype for monthly budgeting.

## Included
- Default monthly income ₹22,000 and sample expense list based on your current budget
- Month-by-month budget storage
- Add, edit, delete and mark expenses as paid/pending
- Pending bills tracked separately (postpaid ₹1,000 is set for next month)
- CSV export
- Offline caching after first load (when served over HTTPS or localhost)

## Try it
Open `index.html` in a browser. For install/offline features, serve it from HTTPS or localhost.

## Android APK
This folder is a working PWA/web-app project, **not a compiled APK yet**. To make an APK, import/host the PWA with a trusted Android wrapper such as Bubblewrap/TWA, or wrap the HTML assets in Android Studio WebView. APK signing/building requires Android build tools and your own signing key. Do not install an APK from an unknown source.
